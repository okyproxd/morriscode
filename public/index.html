⏱ One-Minute Tour

      
Every MorrisCode program is just a list of instructions, one per line. Each instruction looks like this:

      
name(stuff)

      
That's the whole rule. Comments start with * — MorrisCode ignores anything on a line that begins with a star.

      
The most useful instructions in one example:

      
* this is a comment
print(Hello!)               * show text in console
draw(circle:5:gold)         * draw a gold circle, size 5
variable(score : 0)         * remember a number
if(score > 5)            * do stuff only if true
  print(You win!)
end()                       * close the if-block
add(score, 1)               * score = score + 1
wait(500)                   * pause 500 milliseconds


      
🎛 Editor buttons

      
The toolbar above your code:

      
    
        
  • 📂 Open — load a .txt file you saved before. Drag-and-drop also works.
    • 
        
  • 💾 Save — save your code as .txt. A dialog asks for a filename.
    • 
        
  • ✨ Example — load the Snake game starter program.
    • 
        
  • ⛶ Fullscreen — make the editor fill your whole screen. Esc to exit.
    • 
        
  • Clear — erase everything and start over.
    • 
        
  • ⏹ Stop — stop a running program (great for forever-loops).
    • 
        
  • ↻ Restart — stop, then run from scratch.
    • 
        
  • ▶ Run — run your code.
    • 
      

      
The same Run / Stop / Restart / Fullscreen also appear floating on top of the canvas, even in fullscreen mode.


      
👋 Hello, world

      
The smallest program:

      
print(Hello, world!)

      
Press ▶ Run. "Hello, world!" appears in the dark console panel below the canvas.

      
Now let's draw something:

      
draw(circle)

      
An empty circle with a black outline shows up in the middle of the canvas. Make it bigger and colored:

      
draw(circle:8:blue)

      
Try this whole program — it draws and prints:

      
print(Drawing a smiley face!)
draw(circle:9:gold:noborder)
draw(circle:1:black:noborder:700,400)
draw(circle:1:black:noborder:900,400)
draw(text"*o*":4:black:noborder:800,600)


      
🔷 Shapes

      
The drawing instruction is always:

      
draw(shape:size:color:options:x,y)

      
Everything after shape is optional. Without arguments, you get a default-sized empty-fill shape in the middle of the canvas.

🎨 Colors

      
Just type the color name. MorrisCode knows over 200, and case doesn't matter.

      
draw(circle:5:tomato)
draw(circle:5:salmon)
draw(circle:5:sunshine)
draw(circle:5:ocean)
draw(circle:5:lavender)
draw(circle:5:cinnamon)
draw(circle:5:moss)
draw(circle:5:brick)

      
If you can think of an object's color, type it. peach, cherry, storm, cream, mint — they all work.

      
Full color list with previews on the Reference page. Click any swatch to copy the name.


      
📏 Sizes & positions

      
Sizes go from 1 (tiny) to 10 (huge). Default is 4. Anything outside 1-10 throws an error.

      
Positions are x,y in pixels. The canvas is 1600 wide and 1000 tall.

      
    
        
  • Center of canvas: 800,500
    • 
        
  • Top-left: 0,0
    • 
        
  • Bottom-right: 1600,1000
    • 
      

      
draw(circle:5:gold:noborder:800,500)     * center
draw(circle:3:tomato:noborder:100,100)   * top-left corner
draw(circle:3:lime:noborder:1500,900)    * bottom-right corner


      
⚙️ Options (border, thick, dashed)

      
The 4th slot in draw() is for options:

      
    
        
  • noborder — no black outline (great for solid shapes)
    • 
        
  • thick — fat outline
    • 
        
  • dashed — dashed outline
    • 
        
  • default — normal outline (or leave the slot empty)
    • 
      

      
draw(circle:6:tomato:noborder)
draw(square:4:gold:thick:200,200)
draw(star:5:lime:dashed:800,500)
draw(heart:5:pink:default:1200,500)


      
🏷 Naming shapes (ids)

      
Add an id after the shape name with an underscore, so you can refer to it later:

      
draw(star_1:5:gold:noborder:400,500)
draw(star_2:5:lime:noborder:800,500)
draw(star_3:5:pink:noborder:1200,500)

      
Now each star has a name. You can move(), animate(), delete(), or set() any one of them:

      
animate(star_1:spin:4)
move(star_2:3:800,200)
delete(star_3)

      
Ids can be letters or numbers (star_5, square_player, text_score) — but no spaces.

      
If you don't pick an id, MorrisCode picks one for you (circle_1, circle_2, etc).


      
💬 Text on canvas

      
Put words on the canvas (not just the console):

      
draw(text"Hello, world!":5:navy:noborder:800,500)
draw(text"Score: 0":4:white:noborder:200,80)

      
Text uses the same colon-format as shapes, but with a quoted string instead of a shape name.

      
To update text later (like a score), give it an id and use delete():

      
draw(text_1"Score: 0":4:white:noborder:200,80)
* later, when score changes:
delete(text_1)
draw(text_1"Score: {score}":4:white:noborder:200,80)

      
Tip: You can put any variable inside the text using {name}:

      
variable(name : Owen)
draw(text"Hi {name}!":5:navy:noborder:800,500)


      
🔤 Fonts

      
Add a font name as the last slot in a text draw call (the 6th piece, after position):

      
draw(text"Adventure!":7:gold:noborder:800,400:lobster)
draw(text"GAME OVER":8:tomato:noborder:800,500:pixel)
draw(text"my note":4:navy:noborder:800,300:caveat)

      
All font names are lowercase, no spaces, no punctuation. There's a full font gallery on the Reference page — click any font to copy its name.


      
🌌 Background color

      
Sets the entire canvas to one color:

      
background(midnight)
background(skyblue)
background(black)
background(white)

      
Tip: do this once at the top of your program. If you put it inside forever() it'll keep painting over your shapes.


      
📝 Variables

      
A variable remembers a value with a name. Set it once, use it later.

      
variable(score : 0)
variable(name : Owen)
variable(myColor : tomato)
variable(alive : yes)

      
Read a variable by wrapping its name in curly braces:

      
print(Hi {name}!)
draw(circle:5:{myColor}:noborder:800,500)
draw(text"Score: {score}":4:white:noborder:200,80)

      
You can change a variable any time. Whatever was there gets overwritten:

      
variable(score : 0)
print({score})         * prints 0
variable(score : 42)
print({score})         * prints 42


      
⚖️ if() and then()

      
Run code only when something is true. Simplest form:

      
if(score > 5) then(print(You win!))
if(name = Owen) then(beep(C, 200))

      
Comparisons:

      
    
        
  • = — equal
    • 
        
  • != — not equal
    • 
        
  • > — greater than
    • 
        
  • < — less than
    • 
        
  • >= — greater or equal
    • 
        
  • <= — less or equal
    • 
      

      
For more than one line of code in the if-block, span multiple lines and close with end():

      
if(score > 5)
  print(Awesome!)
  draw(star:6:gold)
  beep(G, 200)
end()

      
Shortcut: if(alive) is the same as if(alive = yes).

      
You can nest ifs:

      
if(alive)
  if(score > 10)
    print(High score!)
  end()
end()


      
🧮 Math — the easy way

      
One-word commands instead of long math expressions:

      
add(score, 1)         * score = score + 1
subtract(lives, 1)    * lives = lives - 1
multiply(speed, 2)    * speed = speed × 2
divide(price, 4)      * price = price / 4

      
The first argument is the variable to change. The second is what to add/subtract/etc.

      
Negative numbers work:

      
variable(direction : 10)
multiply(direction, -1)   * direction is now -10


      
🎲 Random numbers

      
random() picks a random number between two values and stores it in a variable:

      
random(dice, 1, 6)        * dice = random 1-6
random(x, 0, 1600)        * x = random canvas position
random(color, 1, 3)       * color = 1, 2, or 3

      
Common pattern — random color picker:

      
random(pick, 1, 4)
if(pick = 1) then(variable(c : tomato))
if(pick = 2) then(variable(c : gold))
if(pick = 3) then(variable(c : lime))
if(pick = 4) then(variable(c : pink))
draw(star:5:{c}:noborder:800,500)


      
🔁 Loops

      
Three ways to repeat code.

      
repeat() — do it N times

      
repeat(5)
  draw(star:3:gold)
  wait(200)
end()

      
loop() — count from one number to another

      
loop(i from 1 to 10)
  print(Number {i})
end()

      
The variable {i} changes each time through the loop. Use it!

      
* draw 10 stars in a row
loop(i from 1 to 10)
  variable(spot : {i})
  multiply(spot, 150)
  draw(star:3:gold:noborder:{spot},500)
end()

      
forever() — until you stop it

      
forever()
  draw(circle:1:gold:noborder)
  wait(50)
end()

      
To stop a forever loop from inside, use stop() or press the ⏹ Stop button.


      
⏰ wait()

      
Pause your program. You can write times in plain English:

      
wait(500)            * 500 milliseconds (half a second)
wait(1 second)       * one whole second
wait(3 seconds)      * three seconds
wait(2 minutes)      * two minutes

      
Same works for beep(): beep(C, 1 second).


      
🚀 move()

      
Slide an existing shape smoothly to a new position:

      
draw(circle_1:5:tomato:noborder:100,500)
move(circle_1 : 3 : 1500,500)

      
Format: move(shape_id : speed : x,y). Speed is 1 (slow) to 10 (fast).

      
The shape needs an id first — that's why we wrote circle_1 instead of just circle.


      
🎬 animate()

      
Built-in animations that loop on a shape until you call stop() or delete() it.

      
draw(star_1:7:gold:noborder:800,500)
animate(star_1 : spin : 4)

      
Animation types:

      
    
        
  • spin — rotate continuously
    • 
        
  • pulse — grow and shrink
    • 
        
  • bounce — bob up and down
    • 
        
  • shake — wiggle
    • 
        
  • fade — fade in and out
    • 
        
  • rainbow — cycle colors
    • 
      

      
Speed is 1-10. Combine animations on different shapes:

      
draw(star_1:5:gold:noborder:400,500)
draw(star_2:5:tomato:noborder:800,500)
draw(star_3:5:lime:noborder:1200,500)
animate(star_1:spin:4)
animate(star_2:pulse:5)
animate(star_3:rainbow:3)


      
🔧 set()

      
Change a property of a shape that's already drawn — without redrawing it from scratch:

      
draw(circle_1:5:gold:noborder:800,500)
set(circle_1:x:1000)              * move it right
set(circle_1:y:300)               * move it up
set(circle_1:color:tomato)        * change color
set(circle_1:size:8)              * make it bigger
set(circle_1:rotation:45)         * rotate 45 degrees
set(circle_1:opacity:0.5)         * half see-through

      
Properties: x, y, pos, color, size, rotation, opacity, border, text.

      
set() is faster than delete + draw, especially in a forever loop.


      
🗑 delete()

      
Remove one shape without erasing the rest of the canvas:

      
draw(square_1:3:gold:noborder:{x},500)
* later:
delete(square_1)

      
Compare with clear(), which erases everything:

      
clear()       * wipe the whole canvas


      
🎮 forever() — the game loop

      
Every game has the same heartbeat: read input → update things → draw → wait → repeat. In MorrisCode that's:

      
forever()
  * 1. read keys
  if(key = ArrowRight) then(add(x, 10))

  * 2. update positions or state
  add(score, 1)

  * 3. redraw shapes
  set(square_1:x:{x})

  * 4. wait so it doesn't run too fast
  wait(30)
end()

      
The wait() at the end controls speed. Lower = faster.


      
⌨️ Keyboard input

      
The variable {key} always holds the most recently pressed key. Use it inside a forever loop:

      
variable(x : 800)
draw(square_1:3:gold:noborder:{x},500)

forever()
  if(key = ArrowRight) then(add(x, 10))
  if(key = ArrowLeft) then(subtract(x, 10))
  set(square_1:x:{x})
  wait(30)
end()

      
Key names:

      
    
        
  • Arrows: ArrowLeft, ArrowRight, ArrowUp, ArrowDown
    • 
        
  • Letters: a, b, c... (lowercase)
    • 
        
  • Numbers: 0, 1, 2...
    • 
        
  • Special: Space, Enter, Tab, Escape, Shift
    • 
      

      
Important: click the canvas first so it knows to listen for your keys. Otherwise it'll just type into the editor.


      
🖱 Mouse input

      
These variables update as you move and click on the canvas:

      
    
        
  • {mouseX}, {mouseY} — where the cursor is right now
    • 
        
  • {mouseDown} — yes if a button is held, no otherwise
    • 
        
  • {clickX}, {clickY} — position of the last click
    • 
      

      
Example — a circle that follows the mouse:

      
forever()
  clear()
  draw(circle:4:tomato:noborder:{mouseX},{mouseY})
  wait(20)
end()


      
💥 Collision

      
Check if two points are close to each other:

      
collide(hit, ballX, ballY, paddleX, paddleY, 50)
if(hit) then(beep(E, 100))

      
Format: collide(answer, x1, y1, x2, y2, distance). The first argument is the variable that gets yes or no.

      
Bigger distance = easier to collide. For tight collisions use 20-30. For loose ones use 60-100.


      
📨 when() — events

      
Run a block of code when something happens, without sticking it inside forever().

      
when(click)

      
when(click)
  print(You clicked!)
  draw(circle:3:gold:noborder:{clickX},{clickY})
end()

      
when(start)

      
when(start)
  print(The game is starting!)
end()

      
when(message, X) + broadcast(X)

      
Send a message from one part of your program to another:

      
when(message, hello)
  print(Got the hello message!)
end()

* later, anywhere:
broadcast(hello)


      
🛠 How to make your own game (step by step)

      
You have all the pieces now. Let's build a simple dodge game where a circle dodges falling squares.


      
Step 1 — Set the scene

      
background(midnight)
draw(circle_1:3:gold:noborder:800,900)


      
Step 2 — Move with arrow keys

      
background(midnight)
draw(circle_1:3:gold:noborder:800,900)
variable(playerX : 800)

forever()
  if(key = ArrowLeft) then(subtract(playerX, 15))
  if(key = ArrowRight) then(add(playerX, 15))
  set(circle_1:x:{playerX})
  wait(30)
end()


      
Step 3 — Add a falling enemy

      
background(midnight)
draw(circle_1:3:gold:noborder:800,900)
variable(playerX : 800)
variable(enemyY : 0)
random(enemyX, 100, 1500)
draw(square_1:2:tomato:noborder:{enemyX},{enemyY})

forever()
  if(key = ArrowLeft) then(subtract(playerX, 15))
  if(key = ArrowRight) then(add(playerX, 15))
  set(circle_1:x:{playerX})

  add(enemyY, 10)
  if(enemyY > 1000)
    variable(enemyY : 0)
    random(enemyX, 100, 1500)
  end()
  set(square_1:x:{enemyX})
  set(square_1:y:{enemyY})

  wait(30)
end()


      
Step 4 — Add collision and game-over

      
* inside the forever loop, before wait():
collide(hit, playerX, 900, enemyX, enemyY, 50)
if(hit)
  draw(text"GAME OVER":8:tomato:noborder:800,500:bungee)
  beep(C, 400)
  stop()
end()


      
Step 5 — Add a score

      
variable(score : 0)
draw(text_score"Score: 0":3:white:noborder:200,80)

* in the forever loop, when enemy resets:
if(enemyY > 1000)
  variable(enemyY : 0)
  random(enemyX, 100, 1500)
  add(score, 1)
  delete(text_score)
  draw(text_score"Score: {score}":3:white:noborder:200,80)
end()

  1. Setup — background, draw initial shapes, set starting variables

🔊 beep() — sound

      
Play a single musical note:

      
beep(C, 200)
beep(E, 200)
beep(G, 400)

      
Notes are C D E F G A B (case doesn't matter). Duration is milliseconds, or words like 1 second.

      
Play a simple tune:

      
beep(C, 200)
beep(D, 200)
beep(E, 200)
beep(F, 200)
beep(G, 400)
beep(F, 200)
beep(E, 200)
beep(D, 200)
beep(C, 400)


      
📋 Lists

      
Lists hold multiple values in order. Useful for keeping track of lots of similar things (like snake body segments).

      
Make a list

      
list(colors, red, gold, blue, green)
list(numbers, 1, 2, 3, 4, 5)

      
Read an item

      
listGet(c, colors, 1)    * c becomes "red" (first item)
listGet(c, colors, 3)    * c becomes "blue"

      
Items count from 1, not 0.

      
Add, remove, change

      
listAdd(colors, purple)      * add to the end
listSet(colors, 2, pink)     * change item #2
listRemove(colors, 1)        * remove item #1
listLength(colors, n)        * n = how many items

⚠️ When something breaks

      
Errors show up in the console with a line number, a plain explanation, and a (?) link that opens these docs.

      
Most common mistakes:

      
    
        
  • Forgot end() — every if(), repeat(), loop(), forever() needs a matching end().
    • 
        
  • Size out of range — sizes are 1 to 10.
    • 
        
  • No shape with id... — you tried to move(), set(), or delete() a shape that wasn't drawn yet.
    • 
        
  • Misspelled color — unknown colors render as gray. Check the Reference page.
    • 
        
  • Forgot the colons — draw() uses colons between parts: draw(circle:5:gold) not draw(circle 5 gold).
    • 
        
  • Variable doesn't update — make sure you used {name} when reading the variable, not just name.
    •
